    Rayburst Connect

    Redefining the companion browser extension

    1Find it in your browser

    Discover HLS/DASH streams and media files in Sniffer, the browser sidebar, or the full-page workspace. Send selected resources to Rayburst.

    2Finish it in Rayburst

    Send browser downloads to Rayburst automatically, set per-site rules, and manage tasks from the popup.

    Preview media before downloading and choose video, audio and subtitle tracks. Requires the Rayburst desktop app. Chrome, Edge and Firefox

    Aria2 Next

    A native engine for files, torrents and streams

    Aria2 Next is the open-source download engine behind Rayburst. It supports HTTP, HTTPS, SFTP, ED2K and BitTorrent, with a command-line interface and JSON-RPC.

    Download HLS/DASH streams, select tracks, record live broadcasts and save to MP4 or MKV without transcoding.
